# Monocular Depth Estimation

## Chay thu

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe monocular_depth_estimation.py --image image.jpg
```

## Ghi chu

- `pyvenv.cfg` trong `.venv` chi la cau hinh cua moi truong ao tren may hien tai, khong phai file cau hinh di dong cho nguoi khac.
- Muon nguoi khac clone ve chay duoc, can chia se `requirements.txt` va huong dan cai dat nhu tren.
